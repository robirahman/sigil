  The 33 new surprise cases come from 37 games played since that audit, via run

* **New-audit summary (v23, 33 confirmed).** Depth 4 saw 0 of them, depth 5 saw 42% and

  positions the search already wins.

## Binding added

`analyze(..., node_limit=N)` adds `Search::node_limit`, which stops the search like the clock
does and keeps the last completed depth. It is deterministic and does not depend on the
machine. It defaults to `None`, so every shipped path is unchanged. It is pinned by
`node_limit_stops_deterministically_at_the_last_completed_depth`. `cargo test --release --lib`
passes 169/169, and the wasm feature build type-checks.
